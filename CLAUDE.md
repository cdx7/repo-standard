# CLAUDE.md

Standing instructions for Claude Code in this repo: rules, not session state.

**This is the PUBLIC copy of repo-standard.** It is made by export from a private upstream, one
release at a time. Do not develop the standard here: a change made in this repository is
replaced by the next export unless it is carried into the upstream. Here, read the standard,
adopt it with the toolkit, and open issues or pull requests.

Personal directives, if any, go in `CLAUDE.local.md`: Claude Code loads it after this file in
every session, and `.gitignore` keeps it out of git.
