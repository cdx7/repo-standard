# CLAUDE.md

Standing instructions for Claude Code in this repo: rules, not session state. Where work
stands lives in `docs/tracking/STATUS.md` and `docs/AI/session-handoffs/`. Keep STATUS true:
check it whenever you write a handoff or change a tracker row's status. Who writes what in
this repo is in `REPO-STANDARD.md`: read it before your first change.

Personal directives, if any, go in `CLAUDE.local.md`: Claude Code loads it after this file in
every session, and `.gitignore` keeps it out of git.
